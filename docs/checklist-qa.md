# Checklist de calidad QA

## Antes de crear un Pull Request

- [ ] Verificar que el proyecto compile correctamente.
- [ ] Revisar el formato del código con Laravel Pint.
- [ ] Ejecutar las pruebas automatizadas con PHPUnit.
- [ ] Comprobar que no existan archivos innecesarios.
- [ ] Revisar los cambios antes de subirlos a GitHub.

## Durante la revisión

- [ ] Comprobar el resultado de GitHub Actions.
- [ ] Revisar los errores reportados por el pipeline.
- [ ] Solicitar la aprobación del responsable del proyecto.

## Antes de integrar a main

- [ ] Confirmar que las verificaciones estén aprobadas.
- [ ] Verificar que el Pull Request tenga la revisión requerida.
- [ ] Confirmar que la documentación esté actualizada.
